# 实验概述：150px 循环滑窗 D-FINE 与 IBO 证据融合

## 研究问题

圆环焊道缺陷具有细长纹理、类别不均衡和尾类易被相似头部类吸收等特点。单阶段检测器在提高候选召回后，仍可能在尾类和外观相近类别之间发生错误分类。本项目将检测与最终判别解耦：D-FINE 负责生成高召回候选，IBO（instance-based object）模块融合多种证据，对候选可靠性和类别进行二阶段判断。

## 方法流程

```text
环形焊道图像
  -> ROI / 焊道展开
  -> 1024 x 150 循环滑窗（stride=768，首尾连续）
  -> D-FINE 候选框
  -> 跨窗口候选合并
  -> IBO 构建：局部外观 + 正常参照距离 + 频率证据
  -> 可靠性融合、尾类阈值校准、混淆类二阶段纠错
  -> 最终缺陷预测
```

## 关键设计

### 保持径向尺度

展开焊道的有效高度为 150 px。训练样本仅向下补边到 160 px，以适配特征步长；不把 150 px 径向信息拉伸到更高尺寸，从而尽可能保持细长缺陷的几何和纹理形态。

### 循环滑窗

每个窗口宽 1024 px、步长 768 px，重叠 256 px。窗口在展开条带首尾按环形连接，避免 12 点钟附近缺陷被硬切开。数据构建脚本还会筛除大量重复空白切片，降低负样本重复对训练的干扰。

### 两阶段决策

D-FINE 在本流程中的定位是候选生成器而不是唯一的最终分类器。IBO 模块可使用候选区域的局部空间特征、与训练集正常参照库的距离，以及频率域异常特征；可靠性分数可用于后处理和尾类专用阈值校准。针对断焊、长焊高塌、缺焊蓝黑等易混类别，代码还提供了二阶段分类实验。

## 当前内部实验结果

在内部验证集的实例级统计中，新版 150 px 循环滑窗模型在 1,124 个非钢帽缺陷实例上取得 85.77% 的候选有效覆盖（964 正确、72 错类、88 漏检）。与此前的展开版本相比，主要变化是漏检显著减少；但尾类仍存在较明显的类别混淆。因此，这些结果支持将模型作为后续 IBO 研究的候选入口，并不表示长尾问题已经被完全解决。

> 这些数字来自非公开工业数据，仅用于说明项目内的实验状态，不能与公开数据集结果直接比较。

## 数据与公开评测

本仓库不含工业数据、标注、权重或中间实验产物。复现时请使用具有授权的数据，并在训练/验证分割、类别定义和评测标准上保持一致。对于公开数据评测，建议采用仓库中 LoHi-WELD 方案所列的固定输入尺寸、阈值扫描和每类指标，同时明确区分“原论文报告值”“复跑值”和“本方法结果”。

## 已知限制

- 现有部分脚本保留了原始实验的默认本机路径；迁移环境时应显式传入脚本参数或修改配置。
- IBO 模块依赖第一阶段候选与训练集构建的正常参照库，必须严格避免将验证或测试图像泄漏到参照库。
- 公开数据集不具备稳定圆环结构时，不应直接套用 150 px 展开滑窗路线，应使用原图检测设置。
