# 2.分析
## 1.拉伸规格
对，这里要按“环形滑窗”来分，不能普通从左到右硬切。
我建议这样定：
`完整展开条带：约 4600×150`  
`单段输入：1024×150`  
`步长：768`  
`重叠：256`

段数按每张图实际宽度自动算：
`段数 = ceil(条带宽度 / 768)`

所以：

|条带宽度|分段数|
|---|---|
|约 `4000`|`6段`|
|`4573 ~ 4608`|`6段`|
|`4609 ~ 5376`|`7段`|
|大于 `5376`|`8段`|

按我们现在这批数据，大多数会是 `7段`，少部分是 `6段`，极少数可能 `8段`。

首尾连续要这样处理：
最后一段不能直接裁到末尾就结束，而是要从条带尾部继续接回开头。比如宽度 `4600` 时，最后一段从 `3840` 开始：
`3840 → 4600` 加上 `0 → 264`
这样焊道首尾是连起来的，12点钟方向附近的缺陷不会被硬切断。

所以最终方案就是：
`1024×150 环形滑窗训练，stride=768，首尾取模连续裁剪`
这比之前 `1024×256` 更合理，因为它保留了 ROI 展开后的真实径向比例。


## 2.问题
### 1.若D-FINE没识别到缺陷后面该怎么办：
不会卡死，关键是：**不能把 D-FINE 最终画出的框当成 IBO 的唯一入口。**
“没画框”只代表它在阈值/NMS 后没有保留预测，并不代表图中没有可分析区域；D-FINE 内部仍会产生一批原始 query。更重要的是，IBO 应该由焊道的空间覆盖来保证，而不是由检测器决定有没有资格分析。
建议把流程固定为：
```
ROI 定位焊道
→ 焊道展开
→ 重叠切成连续小段（每一段天然都是候选区域）
→ D-FINE 原始 query/置信度 + 正常参照距离 + 频率异常证据
→ 可靠性融合与分布校准
→ 得到 IBO 区域热图
→ 合并为缺陷框，并映射回圆形焊道原图
```
也就是说：
- D-FINE 检出框：作为“强候选”，优先进入 IBO。
- D-FINE 未检出，但频率证据或正常参照距离异常：仍可形成 IBO，专门补救漏检。
- 三种证据都正常：该小段不形成 IBO。
训练阶段则直接用人工标注框生成 IBO 监督，不依赖 D-FINE 是否先检测成功；推理阶段用展开焊道上的重叠小段保证全覆盖。
这反而是你后续方法成立的必要条件：如果 IBO 只能来自 D-FINE 已检出的框，那么“正常参照、频率证据、可靠性融合”只能给已有框重新打分，无法解决长尾缺陷的漏检问题。把 IBO 与检测框解耦后，后续模块才真正能补 D-FINE 的短板。
